# Sources: where the house style's rules come from

Read this when you need a rule's source, or a source's license. Every rule here is written in
this skill's own words. Sources are quoted only briefly, with attribution, and each quote is a
dated fact in `facts.md`.

Checked 2026-10-05.

| Source | What it's used for | License | How it's used here |
|---|---|---|---|
| [Google developer documentation style guide](https://developers.google.com/style) | Sentence-case headings, and the words "just", "simply" and "leverage" | CC BY 4.0 (fact `google-license`) | Short quotes, with attribution |
| [Microsoft Writing Style Guide](https://learn.microsoft.com/en-us/style-guide/welcome/) | Sentence-style capitalization | Microsoft's terms of use | One short quote, for a fact |
| [GOV.UK style guide](https://www.gov.uk/guidance/style-guide/a-to-z) | Plain English, and the words "leverage" and "robust" | Open Government Licence v3.0 | Short quotes, with attribution |
| [Vale's documentation](https://vale.sh/docs) | How packages, configuration sections and rule exceptions work | No license stated | Facts with short quotes |
| [Vale](https://github.com/vale-cli/vale) | The checker | MIT (fact `vale-license`) | Run as a tool. Nothing is copied from it |

The HouseStyle package's rules are original to this skill. Where a page states no license, only
short quotes are used.
