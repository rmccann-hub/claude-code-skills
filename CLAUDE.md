@AGENTS.md

Sessions on this repository also load the maintainer's skills synced from claude.ai. They are
older copies of skills this repository is replacing, and this repository's settings cannot turn
them off. Where one disagrees with a file under `skills/`, the file here is the one being worked on.
That goes for an installed copy of this repository's own skill too: `.claude/settings.json` turns
off the plugin's copies, but not one uploaded as a claude.ai skill.
