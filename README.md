# Archive

claude-code-skills' finished work and superseded logs, kept off `main` by the standard's rule on
records (dimension 10, from v0.49.0). `main` lists every item here in `docs/archive.md`.

- **Added to, never edited or deleted.** A new item goes in a folder named by its date.
- **Never merged into `main`.** Commits only add to the previous tip.
- **Public, like `main`:** nothing here names an audited repository. Records that do live in the
  private `audit-reports` repository's `audit-log` branch.
