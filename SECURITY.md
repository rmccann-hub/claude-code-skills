# Security policy

Skills in this repository run inside other people's Claude Code sessions, with their
permissions, and a skill can bundle scripts. A problem here can reach every repository that
installs from it.

## Reporting a problem

Use **Report a vulnerability** on this repository's Security tab. It opens a private advisory
that only the maintainer can see. Please do not open a public issue.

In scope: anything here that could make an agent leak data, run something unexpected, reach
outside the repository it is working in, or weaken a check.
